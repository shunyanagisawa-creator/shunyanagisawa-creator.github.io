デフォルト・ウォーターフォール

Default Waterfall — Default Waterfall

出所 初版 更新 2026年8月2日

CCPが清算参加者のデフォルトに直面した際に、どの資本・リソースから順に損失を吸収していくかを定めた階層構造。典型的には「デフォルト会員のIM → デフォルト会員負担DF → CCP自己資本（SIG） → その他会員負担DF → 追加コール（アセスメント） → 回復・解消措置」の順で構成される。

補説

参加者がデフォルトしたとき、どの資金から順に損失を埋めるかを定めた階層です。デフォルトした参加者自身の当初証拠金と拠出金がまず使われ、次に清算機関の自己拠出金、その次に他の参加者が拠出した清算基金へと及びます。相互化とは、この「他の参加者の拠出に及ぶ」部分を指します。全額担保型の清算機関では最初の層だけで完結する設計になり、後段の層はほとんど働きません。
